# Movie Orbit
 
A Movie Embeddings Visualizer

To locally run the dev server just install the dependencies using `pip install -r requirements.txt`, then run the `run.py` file and it will start the server on port `5000`

To enable GPU usage (Nvidia Only) in the notebook you have to uninstall `torch` then reinstall it using the command from `https://pytorch.org/get-started/locally/` to activate appropriate CUDA support
