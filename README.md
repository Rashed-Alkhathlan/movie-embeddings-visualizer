# Movie Orbit
 
A Movie Embeddings Visualizer

To locally run the dev server just install the dependencies using `pip install -r requirements.txt`, then run the `run.py` file and it will start the server on port `5000`

To enable the GPU in the notebook (Nvidia Only) you have to uninstall the `torch` module then reinstall it using the command from the [PyTorch website](https://pytorch.org/get-started/locally/) to activate appropriate CUDA support
